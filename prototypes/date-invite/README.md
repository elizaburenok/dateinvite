# Приглашение на ужин в конверте

Интерактивная страница-приглашение: получатель открывает конверт, листает карточки
с местами и выбирает одно. Ответ приходит в Telegram.

## Запуск

```bash
npm install && npm run dev
```

Откройте главную страницу, чтобы собрать конверт и получить ссылку. Готовое
приглашение открывается на `invite.html`; его содержимое передаётся в параметре
`draft` ссылки.

## Варианты механики и стиля

Ничего не зафиксировано жёстко — варианты переключаются панелькой «ВАРИАНТЫ»
в правом верхнем углу или прямо через query-параметры:

| Параметр | Значения | Что меняет |
| --- | --- | --- |
| `skin` | `stitch` (по умолч.), `retro` | стиль: вышивка крестиком / игривый ретро |
| `open` | `pocket` (по умолч.), `four` | конверт: обычный карман / раскрытие на 4 стороны |
| `cards` | `tucked` (по умолч.), `center` | карточки: торчат из конверта / стопкой по центру |
| `to`, `from` | любой текст | имя получателя и отправителя |

Пример: `http://localhost:5173/?skin=stitch&open=four&cards=center&to=Лиза&from=Эля`

Рабочие пары: `pocket` + `tucked` и `four` + `center`.

### Как листать карточки

- **Свайп / перетаскивание** влево-вправо — следующая/предыдущая карточка.
- **Наведение мышью** (десктоп) или **тап** (мобильный) — карточка выдвигается из конверта.
- **Перетаскивание вверх** — тоже вытягивает карточку.
- **Стрелки на клавиатуре** — ←/→ листают, ↑/↓ вытягивают и задвигают.

Первая карточка колоды — не место, а текст приглашения.

## Что редактировать

Всё содержимое лежит в [`src/config.js`](src/config.js): текст приглашения,
список мест (до 5), подписи интерфейса и дефолтные варианты.

## Telegram — куда приходит ответ

1. Напиши **@BotFather** → `/newbot` → получи токен.
2. Напиши своему боту любое сообщение (иначе он не сможет ответить тебе),
   затем открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди
   `"chat":{"id":...}`. Либо спроси свой id у **@userinfobot**.
3. Скопируй `.env.example` в `.env` и подставь значения:

```bash
cp .env.example .env
```

```
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_CHAT_ID=123456789
```

4. Перезапусти `npm run dev`.

Токен читается только на сервере ([`api/notify.js`](api/notify.js)) и в клиентский
бандл не попадает. Локально этот обработчик монтируется на `/api/notify`
dev-плагином из [`vite.config.js`](vite.config.js).

Без настроенного `.env` интерфейс работает как обычно: выбор сохраняется в браузере,
а под конвертом появляется мягкое сообщение, что отправить не удалось.

## Как это устроено

Конверт собран из слоёв-сиблингов, между которыми лежит колода — поэтому карточка
одновременно выезжает **из** кармана и поднимается **перед** откинутым клапаном:

```
env-layer--back   (z 1)  задник
deck              (z 4)  карточки  (z 9 в режиме «по центру»)
env-layer--front  (z 5)  карман + адрес
env-layer--flaps  (z 6 → 0 при раскрытии) клапаны
env-layer--seal   (z 8)  печать-пуговица
```

Состояния сцены: `sealed → opening → browsing → confirming → sending → done`
([`src/state.js`](src/state.js)).

Выбор сохраняется в `localStorage`, поэтому повторный переход по ссылке сразу
показывает финальный экран. Сбросить — кнопка «сбросить» в панели вариантов.

## Деплой (когда понадобится)

Структура готова под Vercel: `api/notify.js` подхватится как serverless-функция.
Переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` нужно добавить в настройках
проекта, а не коммитить.
