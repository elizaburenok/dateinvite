# Правило отступов для Invite

- Любой новый или изменяемый фиксированный отступ в интерфейсе (CSS `margin`, `padding`, `gap`, `scroll-margin`, `scroll-padding`; поля и зазоры Auto Layout в Figma; внутренние отступы Canvas) привязывай к существующей переменной `Spacing/002`…`Spacing/120` с шагом 2 px.
- В CSS используй `var(--invite-space-N)`, в Figma — привязку к соответствующей FLOAT-переменной коллекции `Invite / Spacing`. Не создавай разовых значений и новых переменных отступов, даже если в макете указан другой размер: выбирай ближайший доступный чётный шаг. Для значения больше 120 px составляй выражение из существующих токенов.
- Ноль допустим для сброса. Проценты и viewport-единицы допустимы для адаптивной геометрии (например, центрирования или пропорций иллюстрации), но не вместо фиксированного отступа.
- Источник шкалы — `packages/shared/design/figma-spacing.json`; после обновления Figma синхронизируй снимок и запусти `npm run tokens:generate`. Перед завершением запускай `npm run tokens:check`.
