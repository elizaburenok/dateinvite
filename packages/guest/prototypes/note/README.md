# Поле заметки — стенд материала

Стенд для подбора материала панели `.note` — поля ответа под выбранной
карточкой на гостевой странице.

Зачем: на живой странице панель читается плотным цветным пятном, и на глаз не
разобрать, что именно её утяжеляет. Причин три, и они сложены в один материал:

- `saturate(1.4)` в `backdrop-filter` — стекло делает обои под собой **насыщеннее**
  фона, поэтому пятно контрастирует не светлотой, а цветом;
- заливка `rgba(255, 255, 255, 0.35)` поверх этого — ещё треть белил;
- `var(--sh-card)` — тень карточки-героя (`0 26px 54px /.2`) под панелью в 117px.

Стенд разбирает их на отдельные ручки и ставит варианты рядом — на тех же обоях
и под той же карточкой, что у гостя.

Это **прототип, а не часть сборки гостя**: один самодостаточный HTML без React,
Vite и зависимостей. Правила `.note` скопированы из
`packages/guest/src/styles/note.css`, токены — из
`packages/shared/styles/tokens.css`. При правках в проекте копию здесь придётся
обновить руками.

## Как открыть

```bash
node -e "const h=require('http'),f=require('fs'),p=require('path'),root='packages/guest',T={'.html':'text/html; charset=utf-8','.css':'text/css','.js':'text/javascript','.jpg':'image/jpeg','.webp':'image/webp','.png':'image/png','.svg':'image/svg+xml'};h.createServer((q,s)=>{let u=decodeURIComponent(q.url.split('?')[0]);if(u==='/'){s.writeHead(302,{Location:'/prototypes/note/'});return s.end()}if(u.endsWith('/'))u+='index.html';const fp=p.join(root,p.normalize(u).replace(/^(\.\.[\/])+/,''));f.readFile(fp,(e,d)=>{if(e){s.writeHead(404);return s.end('404')}s.writeHead(200,{'Content-Type':T[p.extname(fp)]||'application/octet-stream'});s.end(d)})}).listen(5202,()=>console.log('http://localhost:5202'))"
```

Из корня репозитория; откроется на `http://localhost:5202`. То же самое лежит в
`.claude/launch.json` под именем **note** — из Claude Code стенд поднимается
оттуда.

Двойным кликом по `index.html` он тоже открывается: обои и фото лежат по
относительным путям, а `file://` их отдаёт. Сервер нужен, только если браузер
капризничает с локальными файлами.

Корень сервера — `packages/guest`, а не папка стенда: обои берутся из
`../../src/assets/wallpaper.webp`, то есть из проекта, а не копией. Одним файлом
меньше расходится с гостем.

## Что на стенде

**Десять вариантов** — «Сейчас» (как на странице), выбранный вариант и восемь
правок. Стенд открывается на выбранном (**Молочное подрезанное ✓**) — том, что уже
ушёл в `note.css`.

| | что меняет |
|---|---|
| **Молочное подрезанное ✓** | **выбранный, в `note.css`:** молочный материал E + подрезанная геометрия A+ (поля 10/14/12, gap 6, строка 30, «Send» 17, радиус 32) |
| **A. Тоньше стекло** | та же конструкция, другие дозировки: заливка .35→.16, `saturate` 1.4→1.02, blur 12→18, тень карточки → своя мягкая |
| **A+ Рекомендация** | A плюс подрезанная пустота: поля 10/14/12, gap 6, строка 30, «Send» 17 — панель ~92px вместо 117 |
| **E. Молочное** | `saturate` 1.0 — стекло не насыщает обои под собой, контраст держит светлотой, а не цветом; заливка .22 белым, blur 16, своя мягкая тень |
| **F. Тонировка под обои** | заливка не белая, а в тон обоям (206,226,184): панель не белеет пятном, а уплотняет фон под собой — контраст тоном, а не светлотой |
| **G. Нимб** | A+ по геометрии, но тень одна: широкая мягкая амбиентная (без ближней) — чистый нимб под панелью вместо двойной тени |
| **B. Контур** | ни заливки, ни блюра, ни тени — одна белая волосяная кромка |
| **C. Строка** | плашки нет вовсе: подпись, строка, линейка под ней |
| **D. Вдавленное** | не парит, а утоплено в обои: внутренняя тень сверху, свет снизу |

**Ползунки** правят выбранный вариант поверх его чисел: заливка, насыщенность,
размытие, кромка, тень, вдавленность, радиус, высота строки, кегль «Send».
Переключение варианта их сбрасывает — ручка, пережившая переключение, врала бы
про вариант. Ручки, которых у варианта нет по устройству (заливка у «Строки»,
размытие у «Контура»), гасятся, а не прячутся.

**Посадка (десктоп / телефон)** — сегмент над тумблерами. «Телефон» ставит панель
на фикс-блок `@media (max-width: 420px)` из `note.css` (радиус 24 round, поля
12/12/16, gap 8, строка 32, «Send» 19) и сужает её до грани карточки. Материал
телефон наследует от выбранного варианта — ради этого мобильный вид и нужен:
лёгкое стекло обязано держаться и на тесной посадке. Геометрические ползунки
(радиус, высота, «Send») в этом режиме гасятся и показывают мобильные числа:
править их на телефоне нечего, посадка выбрана.

**Тумблеры сцены:**

- *состояние фокуса* — в проекте заливка прыгает .35 → .50; на лёгкой базе тот же
  шаг читается вспышкой, и это видно сразу. Работает и живой фокус: клик в поле
  даёт `:focus-within` (тот же материал) и в поле можно набирать — строка растёт
  под текст, ghost-пример уходит;
- *пустое поле* — без примера-подсказки;
- *все сразу* — шесть панелей в столбик для прямого сравнения (ползунки тогда не
  применяются, каждый вариант стоит на своих числах);
- *карточка сверху* — вес над полем, ради которого стенд и не показывает панель
  в вакууме;
- *участок обоев* — бледный верх, центр, синее пятно: материал стекла на них
  ведёт себя по-разному, и лёгкий вариант обязан держаться на всех трёх.

**Панель CSS** собирает из текущих чисел готовый блок для `note.css` — в той же
форме, в какой правило живёт в проекте (две заливки `padding-box`/`border-box`,
слои тени одной строкой), чтобы вставлять заменой.

## Чего стенд не делает

- **Мобильная геометрия не настраивается.** Сегмент «Телефон» показывает панель на
  фикс-блоке `@media (max-width: 420px)` из `note.css`, но сами мобильные числа
  (радиус, поля, «Send») на стенде не крутятся — посадка уже выбрана, стенд лишь
  проверяет на ней материал. В выводе CSS мобильный блок печатается с этими
  числами: правишь материал — телефон его наследует.
- **Карточка места упрощена** — фото со скримом вместо стеклянного кольца на
  SVG-фильтре. Её роль здесь — вес над полем, а не собственный пиксель.
