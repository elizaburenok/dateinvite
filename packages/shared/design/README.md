# Invite: библиотека цветов и отступов

Источник — пять макетов на [странице «Токены»](https://www.figma.com/design/DoN18tOC8qla0R8XMEsCEZ/Untitled?node-id=832-348). [Образцы библиотеки](https://www.figma.com/design/DoN18tOC8qla0R8XMEsCEZ/Untitled?node-id=848-129) находятся рядом с макетами.

[Шкала отступов в Figma](https://www.figma.com/design/DoN18tOC8qla0R8XMEsCEZ/Untitled?node-id=854-134) содержит 60 переменных `Spacing/002`…`Spacing/120` с шагом 2 px. Все ненулевые поля и зазоры Auto Layout в пяти исходных макетах и цветовой библиотеке привязаны к ним (115 привязок). Ноль остаётся сбросом. `figma-spacing.json` хранит ID и значения, а генератор создаёт `styles/figma-spacing.css` с именами `--invite-space-2`…`--invite-space-120` и числовой объект `SPACING` для Canvas.

Для фиксированных CSS `margin`, `padding`, `gap` и прокрутки всегда использовать переменную шкалы. Нечётное значение из макета заменять ближайшим чётным шагом; для размеров больше 120 px составлять выражение из существующих токенов. Старые `--s-1`…`--s-7` остаются алиасами и больше не содержат собственных чисел. Адаптивные проценты и единицы viewport сохраняют пропорции сцены. Проверка `npm run tokens:check` останавливается при появлении фиксированного отступа без токена. Это правило также закреплено в корневом `AGENTS.md` для будущих изменений проекта.

`figma-tokens.json` хранит Figma ID, точные значения, области применения и CSS-имена 19 цветов: 10 основных, 3 стопа градиента, 6 прежних `color/*` для совместимости. `figma-source.json` — снимок исходных привязок всех пяти экранов. Цвета сохраняются с дробными каналами sRGB и исходной прозрачностью; близкие значения не объединяются автоматически.

## Обновление

1. Изменить значения переменных / стиль Gradient/Primary в Figma.
2. Обновить экспорт `figma-tokens.json` и/или `figma-spacing.json`, сохранив ID, имена и привязки `gradientStops[].boundVariables`. Фоновая синхронизация с Figma не включена; для повторной выгрузки можно попросить Codex синхронизировать эту библиотеку.
3. Запустить `npm run tokens:generate` из корня проекта. Генерация создаёт общий CSS, описание градиента для TypeScript и пять SVG из шаблонов.
4. Запустить `npm run tokens:check` и `npm run build`. Сборка shared также запускает генератор.
5. Для отдельного `feed-preview.html` дополнительно выполнить `npm run build:feed-preview -w @invite/miniapp`. Готовая папка `packages/miniapp/feed-preview-dist` содержит HTML, изображения и worker для обработки фото; её можно раздавать статическим HTTP-сервером.

## Потребители

`styles/tokens.css` импортирует сгенерированный `styles/figma-tokens.css`, поэтому оба приложения и предпросмотр получают общие значения. Старые токены, совпадающие с `color/*`, остаются алиасами. Новые цвета не зависят от старых переопределений тёмной темы.

`SelectedPlaceHeading` использует CSS-переменные в SVG-тексте; `WheelCaption` читает их через `getComputedStyle` при рисовании Canvas. При изменении CSS во время работы Canvas обновляется на следующей перерисовке (например, resize). Направления градиентов и геометрия надписей остаются у соответствующих потребителей; цвета, позиции и opacity берутся из одного источника. CSS-переменная полного градиента — образец с направлением 45°, не универсальная геометрия всех надписей.

Внешние SVG внутри `<img>` не наследуют CSS страницы. Поэтому `svg/` содержит исходную геометрию с именованными плейсхолдерами, а генератор подставляет те же токены в конечные файлы: заголовок Home, фон и крестик закрытия, отправка и стрелка назад. При изменении токенов их нужно пересобрать. Не править сгенерированные SVG вручную; размеры, пути и фильтры сохраняются из шаблонов.

## Границы этой синхронизации

Связаны цвета пяти указанных экранов, включая состояния выбора и фокуса с теми же семантическими ролями. Библиотека показывает строки с фотографией, названием и адресом по макету `832:394`; выбор мест для конверта сохраняет сетку. Цвета и отступы списка, включая цвета теней, используют существующие токены. Фотографии мест загружаются из данных пользователя. В остальных экранах тени без цветовых привязок остаются отдельными эффектами.

В Figma добавлены отсутствовавшие привязки Border/01 на `832:391` и `832:393`. Текст Tondo `832:378` остался с исходным цветом: Figma MCP не может редактировать этот текст без отсутствующего в его окружении шрифта Inter Tight. В коде все подписи колеса читают Primitive/Primary.
